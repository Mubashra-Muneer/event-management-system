# Event Management System

A React app where users can explore events from the Ticketmaster Discovery API, register for events and manage their registered events.

## Technologies
- React
- Redux Toolkit
- React Router
- Ticketmaster Discovery API

## Setup
1. Clone this repository
2. Run npm install
3. Get an API key (Consumer Key) from https://developer.ticketmaster.com/
4. Create a file named .env in the project root, copy the line from .env.example and paste your key after the equals sign
5. Run npm run dev
6. Open the local address shown in the terminal

The .env file is ignored by Git, so your API key is never uploaded.
