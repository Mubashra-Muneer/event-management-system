# Event Management System

A React app where users can explore events from the Ticketmaster Discovery API, register for events and manage their registered events.

## Technologies
- React
- Redux Toolkit
- React Router
- Ticketmaster Discovery API

## Setup
1. Clone this repository
2. Run npm install
3. Run npm run dev
4. Open the local address shown in the terminal

More instructions (API key setup) will be added as the project grows.
